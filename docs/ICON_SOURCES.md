# Section heading icons

The five homepage headings use Lucide SVGs from the official repository at revision `7faf87628a1ad6175975bc595344337ce14a7db4`:

- About: `user-round`
- Experience: `briefcase-business`
- Publications: `book-open`
- Selected projects: `blocks`
- Writing: `pen-line`

Source: https://github.com/lucide-icons/lucide/tree/7faf87628a1ad6175975bc595344337ce14a7db4/icons

Copies are kept in `_includes/icons/`, with decorative accessibility attributes added. Shapes and the 24px viewBox are unchanged. CSS renders each at 18px; the original 2-unit stroke scales to 1.5px. Icons use the secondary text color, with a 9px gap before the visible heading label. They are hidden from assistive technology and cannot receive keyboard focus. No external requests, JavaScript or icon package are required.

The ISC copyright and permission notice is included in the distributed site at `assets/icons/lucide-LICENSE.txt`.
