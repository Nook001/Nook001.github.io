This example shows how a short technical note can look on the site.

## Start with the content

A personal homepage can begin with a name, a few experiences, selected projects and a list of notes. Each section has a different job, so it helps to keep the hierarchy clear.

Markdown keeps writing close to the source. A minimal page needs only a title, a short description and the text itself.

```yaml
title: "A useful technical note"
description: "The problem and the idea in one sentence."
```

## Leave room for evidence

When a note discusses a real project, add the context, a concrete decision and the evidence behind any result. A small code example or a screenshot is often more useful than a long list of technologies.
